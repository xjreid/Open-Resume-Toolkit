These unmodified Liberation Sans faces come from the pinned pdfjs-dist 6.3.289 standard_fonts directory. They are compiled into the PDF renderer for the Modern layout; no system font discovery or network access is used. See LICENSE_LIBERATION for the license and document-embedding exception.

Liberation Serif 2.1.5 (Regular, Bold, Italic and Bold Italic) comes unmodified from the bundled LibreOffice runtime 26.909.12148. Its name table identifies version 2.1.5 and SIL OFL 1.1. Copyright notices and the license from that distribution are in OFL_LIBERATION_SERIF.txt. Upstream: https://github.com/liberationfonts/liberation-fonts/tree/2.1.5 . These faces preserve Times New Roman metrics in the Technical PDF; all font data is compiled in, without host font discovery.

Gelasio Regular, Bold, Italic and Bold Italic are unmodified from SorkinType/Gelasio commit 7ab20e7e5c42791e603b9ee3201a0b49849cfdb2. They provide Georgia-compatible metrics for the Professional PDF. The exact source paths and SIL Open Font License are retained alongside the fonts; sha256.json records every bundled TTF.

Professional uses the bundled Liberation Serif faces for characters outside Gelasio’s coverage (including Greek and Cyrillic). Both families are included in its receipt hash; host font fallback remains disabled.
