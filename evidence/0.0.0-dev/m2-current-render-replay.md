# M2 verified current-bundle render replay

Follow-up: retained immutable published revisions were added on 2026-09-04; see
[the retained-published replay checkpoint](m2-retained-published-replay.md).
The limitations below describe this earlier checkpoint.

Date: 2026-09-03. Base commit: `104d8aa`; implementation changes are
uncommitted. Local verification platform: macOS arm64. Status: implemented and
synthetically verified; refreshed installed-app and cross-platform evidence
remain pending.

## Implemented boundary

- The generated replay request accepts one canonical UUIDv7 render-manifest ID.
  It accepts no source, revision, resume content, PDF bytes, path, renderer,
  template or font selector from the WebView.
- The native command resolves the manifest inside the active encrypted profile
  and loads only the exact current draft or latest published revision recorded
  by that manifest. A missing or superseded current revision is unavailable;
  newer content is never substituted.
- Rendering uses the pinned in-memory renderer and its existing bounded native
  operation lease. Generated bytes are discarded unless the complete receipt
  equals the stored receipt: document/schema hash, PDF hash, renderer, template,
  font bundle, page count and byte count must all match.
- A verified replay becomes the same expiring, identity-bound native preview as
  a normal render and may use the existing exact-byte export path. The successful
  replay updates the matching bounded history counter.
- The UI disables replay for receipts whose source is not the current matching
  revision and explains that they remain inspection-only. Client validation
  independently checks source, revision and the complete receipt.
- Committed all-local-data deletion now remounts the PDF panel immediately,
  releasing WebView-held preview bytes and clearing stale history state in
  addition to the native preview cache.

## Deliberate limitation

This checkpoint does not retain historical draft bodies, expose an arbitrary
published revision to the WebView, or bundle superseded renderer/template/font
binaries. Consequently it completes safe replay for compatible exact current
sources, not universal historical replay. Native installed-app keyboard and
screen-reader checks and supported macOS/Windows CI remain M2 release gates.
