## Automated/build checks

- `just check` passed locally: formatting, TypeScript, frontend tests/builds,
  static security checks, strict workspace Clippy, and Rust workspace tests.
  The opt-in native-vault mutation test remained ignored as intended.
- Generated contracts regenerated byte-for-byte identically. Request tests deny
  paths, content, overwrite flags, unknown sources, and invalid revisions.
  Response validation rejects unexpected fields, unbounded sizes, and mismatched
  source/revision identities. Transport failure is not automatically retried.
- Formatter golden tests cover Unicode, line endings, canonical order, empty
  fields, metadata omission, literal script-like text, and control rejection.
- Writer tests cover complete output, limits, reserved names, existing targets,
  final-publication races, cleanup, Unix permissions, dangling target symlinks,
  and selected-parent replacement without destination redirection.
- Lifecycle tests wait for export and preserve concurrent edits/save failures.
  Backend tests enforce one active operation and exact saved revision selection.
  Frontend capability regression tests forbid new filesystem/dialog/process
  grants. The plugin filesystem dependency is not initialized as a plugin.
- The macOS arm64 preview build and `codesign --verify --deep --strict` passed.
  Executable SHA-256 is recorded in `manifest.json`.
- Production JavaScript dependency audit reported no known vulnerabilities.
  See `m2-export-dependencies.md` for dependency review and audit limitations.
- CI now runs text formatter/domain/filesystem tests on all three desktop
  runners. The user reported the previous push green; this changed workflow
  and checkpoint have not yet run remotely.

## Remaining gates

M2 is not complete. PDF/DOCX parsing remains disabled pending OS containment;
import review, PDF preview, DOCX output, historical render metadata, storage
management, and the full offline journey remain unfinished. No AI/browser bridge
or remote endpoint was enabled.

Text export currently supports new files only and requires hard-link support.
Crash/failed-write cleanup can leave unencrypted sibling staging; no automatic
recovery scan exists. Cleanup and directory-durability failures after publication
are reported as warnings about an already-written file. Failure injection for
these warning paths, crashes/full disks, Windows ACL/reparse-point and native
Save-dialog tests, network/removable/synced filesystems, and accessibility/scaling
matrices still need evidence. Windows currently inherits the destination ACL.

Quit-during-native-dialog interaction remains an automated-policy/backend check,
not native timing/fault-injection proof. The known macOS Dock/system-shutdown
termination gap is unchanged. A RustSec audit and signed distribution/SBOM/notice
checks remain release gates. This preview must use synthetic data only.
