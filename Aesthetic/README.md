# Open Folio application design

The user approved the Open Folio redesign and logo on October 4, 2026. It replaces the prior Precision Workbench / Quiet Navy / Offset Open Frame application aesthetic.

- [Current design system](../DESIGN.md) records implementation tokens and component rules.
- [Implementation brief](../docs/development/ui-revamp-2026-10-04.md) records the approved direction, scope, and verification boundaries.
- [Approved mockups](UI-Revamp-Concept-2026-10-04/README.md) preserve the original six-page proposal.
- [Implemented screenshots](UI-Revamp-Implementation-2026-10-04/README.md) show the actual React UI.
- [Current logo masters and application icons](Logo/README.md) contain Open Folio SVG, PNG, ICNS, and ICO assets.
- [Previous UI reference](<previous refrence/README-archive.md>) preserves the old UI plans, pictures, logo exports, native icons, source styles, and fresh before-change captures.
- [Professional document examples](Resume-Designs/README.md) remain independent and unchanged.

Presentation is the scope of this migration. Existing editor, publication, import, export, AI, monitoring, settings, tracker, and captured-job overlay workflows remain feature-owned. Native commands, persistence, permission boundaries, and PDF/DOCX renderers are unchanged.
