# Edge packaging

The shared TypeScript build produces a capture-disabled Edge scaffold. Functional
Edge capture and its development walkthrough remain M5 work. Final Add-ons
identity, publication, signed host/desktop integration, and installed production
qualification belong to M7.

A successful shared build is portability coverage, not evidence that Edge capture
works. See the [extension README](../../../apps/extension/README.md) and
[current implementation map](../../../docs/development/current-state.md).
